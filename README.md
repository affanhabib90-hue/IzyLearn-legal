# IzyLearn-legal

Public IzyLearn privacy policy, terms, and support pages (GitHub Pages).

The pages published here mirror `docs/legal-site/` in the IzyLearn app repository
(https://github.com/affanhabib90-hue/IzyLearn), which is the source of truth.
When the app's legal text changes there, copy the updated pages into this
repository:

| Source (`IzyLearn` repo)               | Published here                    |
| -------------------------------------- | --------------------------------- |
| `docs/legal-site/index.html`           | `index.html`                      |
| `docs/legal-site/terms.html`           | `terms-and-conditions.html`       |
| `docs/legal-site/support.html`         | `support.html`                    |

`privacy-policy.html` is a legacy URL that redirects to `index.html`. Keep it so
old links and bookmarks keep working, and update all footer/nav links on the
published pages to match the table above.

Live site: https://affanhabib90-hue.github.io/IzyLearn-legal/
